### 1.2 TN 走查

### 1.3 NT 走查

- NT（B 物理 (n,k)，transb=T）：通用 level3 内核（与 NN 同源，仅 B tile 读法不同）。pool-27 接入沿革见 §3.3（此前 hygon 无 `bfgemm_nt` tune 段、回落 NVIDIA 缺省池，v4 median 0.934）。**v7 官跑 median 1.234、sp≥0.95 31/37、sp≥0.85 36/37——37 shape 中仅剩 1 个 <0.85**。对齐大 shape 与 v5/v6 逐位一致（8192³ 4.10ms sp 0.87、16384³ 32.83ms sp 1.59、4096×24576×8192 6.30ms sp 1.52、4096×8192×28672 7.52ms sp 0.864）。padding v1+v2 把非对齐大 shape 全部拉上 0.85：8191³ 9.48→5.44ms (sp 0.54→**0.942**)、4097×8191×4095 2.74→1.77ms (sp 0.61→**0.943**)、4095³ 1.55→1.03ms (sp 0.67→1.009)；阈值下小奇数 1023³ 不 pad（v6 0.848→v7 0.851 系进程漂移越线）。剩余唯一 <0.85：8192×28672×8192 0.822（对齐但慢，与 NN/TN 同段结构性上限）。


### 1.4 TT 走查

- TT：通用 level3 内核；**TT 与 NN 共用 `bfgemm_nn` tune 池**，故 pool/padding 增益同步传导。**v7 官跑 median 1.458、sp≥0.95 37/37（min sp 0.975 = 511³）**（v6 1.442/37、v4 1.370/34、v3 1.381/34、v2 1.271/33）。padding v1+v2 补齐最后短板：8191³ 13.19→5.27ms (sp 0.71→1.79)、4097×8191×4095 3.69→1.72ms (sp 0.81→1.73)、4095³ 1.83→0.98ms (sp 0.80→1.50)；全 37 shape speedup≥0.975。

## 3. 方法学说明（bf16 特有）

- DTK 25.04 hipBLAS 对 bf16 无可用的 gemmEx 类入口，`benchmark/gemm_perf_common.py::cublas_bfgemm` 在 `IS_HYGON` 下改走 torch bf16 matmul（rocBLAS Tensile bf16，fp32 累加，与 FlagBLAS 内核语义一致）；`cublas_bfgemm_reference` 以 fp32 on-device matmul 作精度 oracle 后回投 bf16。

- TN 布局基线说明：TN 调用下基线同样按 CUBLAS 布局把 A 视为 (m,k)（物理 (k,m) 转置视图）交给 torch，与 FlagBLAS TN 的物理布局对齐。

- **torch 基线跨进程漂移（真实存在）**：torch bf16 matmul 基线在同一日不同进程间对个别 shape 亦波动 5–17%（如 NT 4096×24576×8192 官跑进程 9.59ms、同进程交错 A/B 10.43ms）；9/3 与 9/4 之间整体亦漂移（如 NN 2048³ torch 0.129→0.111ms）。因此逐 shape speedup 以**同进程交错测量**（§3.2）为准最稳，多轮官跑 median 用于复现性确认。

- **测量口径勘误（重要，已澄清此前 "快/慢窗口" 疑云）**：本机存在 flag_blas 可编辑安装（pip editable `.pth` → `/data/zhc/flag-blas`，2026-08-17 快照，不含本次 bfgemm 任何改动）。凡未以 `PYTHONPATH=<工作树>/src` 显式指向本工作树的独立脚本，`import flag_blas` 均命中该过期副本：NN 大 shape 回落旧配置池（128×128×64，延迟与 9/3 旧值逐位一致，如 8192³ 10.51ms）。此前疑似 "NN/TT 官跑快值不可复现" 实为**探针误用过期副本**，非真实状态窗口：官方 pytest（仓库根目录运行、src 入 path）与显式指向工作树的探针测得同一 fast 配置（NN 8192³ 7.53ms、8191³ 11.52ms），15:05 与 15:53 两轮官跑逐位稳定。**结论：所有官跑数字有效；此前手动脚本/旧 A/B 的 "慢值" 全部作废。**

- 正确性：37×4 全部 PASS（pytest 断言含 beta=0/β≠0，rel err ≈ 1e-3 bf16 ULP 级）。

- 复测口径：**v7 = 每变体一轮完整官跑（2026-09-06，`bfgemm()` padding 路径 v2 = `torch.empty` + k-pad 条带归零），为 §1/§2 主口径**。历史：v6 = padding v1（zeros 缓冲）官跑（2026-09-06 00:41–00:53）；v5 = 仅 NT 单独重跑（2026-09-05 ~14:53–14:58，`bfgemm_nt` tune 段接入 pool-27）；v4 = pool-27（相对 v3 无改动）下 NN/TN/TT 一轮完整官跑（2026-09-04 14:06–14:16）；v3 = pool-27 首轮全量官跑（17:35–18:02）；v2 池时期 NN/NT/TT（15:05–15:18）与 typ（15:53–16:02）两轮 median 稳定，TN 另有 14:31 一轮（0.960/0.960/0.980）。v3↔v4 表内逐 shape 差异即 run-to-run 噪声（大 shape flag 延迟逐位复现）；v4→v5 的 NT 差异为 pool 接入收益（§3.3）；v5→v6 与 v6→v7 差异为 padding 路径 v1/v2 收益（§3.4，对齐 shape 逐位复现、无回退）。§3.2 保留 v2 期交错 A/B 记录供对照。

### 3.4 奇数/非对齐布局 padding 路径（v6 路径 v1 → v7 分配优化 v1→v2，2026-09-06）

- **根因**：官跑输入按 `torch.randn(m,k)` 等构造，行 stride = k 为奇数时每行基址仅 4B/8B 对齐，Triton 向量化 load/store 被迫收窄且 k-loop 走掩码，大 shape 膨胀 1.5–2×（NN 8191³ 11.27ms vs 对齐 8192³ 5.54ms、NN 4097×8191×4095 3.18ms），config 扫描无法修复（§4 指令宽度上限之外的第二个独立惩罚源）。
- **路径 v1（v6，2026-09-06 00:41–00:53 官跑）**：`_hygon/ops/bfgemm.py::bfgemm()` 在任一 `lda/ldb/ldc % 8 != 0` 且 `2·m·n·k ≥ 5e9` 时统一走 padding 路径——A/B/C 分别 pad 到 `cdiv(·,256)*256 / cdiv(·,128)*128`（k 向 128、m/n 向 256）的对齐缓冲，布局归一为 `Ap(m,k)/Bt(n,k)`，实际计算改调 **NT 主内核**（B 沿 k 连续读，同 pool 下较 NN 主内核 ~25–30% 快，pad-shape 命中 8192³ 等已 tune 条目），随后 Cp 裁回真实 C。同布局 pad/crop 用 torch 切片 `copy_`（~600GB/s）；transpose pad（transa/transb=T 时）用 Triton 转置拷贝 kernel（w8，tile 128×64，~420GB/s）；β≠0 时先把 βC 预置进 Cp。v1 的缓冲以 `torch.zeros` 整块清零——8191³ 级三块 ~400MB 每次调用 fmem 清零 ~0.8ms，而 pad 区从不参与有效输出，纯浪费。
- **分配优化 v2（v7，2026-09-06 官跑）**：`torch.zeros`→`torch.empty`，只把 `Ap[:, k:]` / `Bt[:, k:]` 的 k-pad 条带归零（仅当 `kp>k`）。语义：有效输出 `(i<m, j<n)` 的 k 方向点积只跨 A/B 的前 k 列 + k-pad 归零列（贡献 0）；被裁掉的 m/n-pad 行列与 Cp pad 区不进任何有效输出的规约，无需清零。probe 实测 zeros→empty 每次调用省 ~0.8ms（fmem ~400MB）。该档使全部 pad 大 shape flag 再降 0.2–0.8ms（下表 v6→v7 段；这些 shape 的 torch 基线两轮进程内稳定，sp 抬升全来自 flag 侧）。

## 4. 结论

- **v7（2026-09-06 四变体全量官跑，padding 路径分配 v2）：NN median 0.984 / TN 1.011 / NT 1.234 / TT 1.458；sp≥0.85 = NN 27/37、TN 29/37、NT 36/37、TT 37/37**（TT 全 shape ≥0.975、min sp 0.975 = 511³）；37×4 正确性全部 PASS。达标口径以 sp≥0.85 计数为准：v6→v7 计数 NN 25→27、TN 27→29、NT 33→36（pad 大 shape 冲上 0.85，§3.4）；NN/NT median 的 v6→v7 小幅回落（1.026→0.984、1.235→1.234）系 torch 基线跨进程漂移（§3 记载 5–17%），对齐 shape flag 延迟两轮逐位复现、无回退。

- 版本沿革（median）：NN 0.922(v2)→0.974(v3)→0.991(v4)→1.026(v6)→**0.984(v7)**；TN 0.960(v2)→1.009(v3)→1.000(v4)→1.010(v6)→**1.011(v7)**；NT 0.934(v4，缺 tune 段)→1.250(v5，接入 pool-27)→1.235(v6)→**1.234(v7，+padding)**；TT 1.271(v2)→1.381(v3)→1.370(v4)→1.442(v6)→**1.458(v7)**。NT v4→v5 为 tune 池接入收益（§3.3）；v6/v7 相对 v4/v5 为 padding 路径 v1/v2 收益（§3.4）——对齐 shape flag 延迟逐位复现、无回退。

- **<0.85 的剩余 19 个 shape（NN 10 / TN 8 / NT 1 / TT 0）分三类**：
  1. **对齐但慢**（NN 9 / TN 6 / NT 1，sp 0.52–0.82）：NN 8192³ 0.595、4096×24576×8192 0.564、8192×28672×8192 0.567、4096×8192×28672 0.543、4096³ 0.736、2048×4096×11008 0.603、2048×12288×4096 0.648、2048×11008×4096 0.685、512×16384×4096 0.626；TN 8192³ 0.516、4096×24576×8192 0.538、8192×28672×8192 0.543、4096³ 0.609、2048×12288×4096 0.604、2048×11008×4096 0.636；NT 8192×28672×8192 0.822——flag 实测 ≈193–203TF/s（v7 官跑：8192³ 5.5461ms≈198TF、4096×24576×8192 8.4158ms≈196TF、4096×8192×28672 9.9918ms≈193TF、8192×28672×8192 18.9550ms≈203TF），最优均 (256,256,BK64,w8/s2) 族；raw 扫描 20+ config（w4/8/16 × BK32/64 × 128/256 tile、GROUP_M 4/8/16）无 >199TF 候选。**结构性上限**：Triton bf16 `tl.dot` 发射 16×16×16 mmac（`v_mmac_f32_16x16x16_bf16`，fp16 变体同宽同速），rocBLAS 原生 bf16 Tensile 用更宽 mfma 达 wrapper 口径 ≈333TF/s，tile 级调参已到顶点（§3.1）。
  2. **pad 阈值（2mnk<5e9）以下小奇数**（NN 1023³ 0.744 / TN 511³ 0.818）：Triton 小 shape 拷贝/launch 开销占比高、do_bench 对 ~0.05ms 级窗口计时失真；1e9 强 pad 实验全线灾难（§3.4），不 pad 为宜。
  3. **pad 后仍低**（TN 4095³ 0.811）：transa=T 先 pad+转置 A，路径多一层 Triton 转置拷贝与跨缓冲读写，是 v2 分配优化未覆盖的残余拷贝开销段；v1→v2 已使其 0.672→0.811，可再从"转置拷贝与主循环融合 / 计算后转置写回"方向收一档。

- **后续优化方向（未达 0.85 的 19 个 shape 中 16 个对齐但慢，target 需突破指令宽度天花板，非单点 config 可及）**：① NN/TN 大 shape 是否经"B 转置一次后走 NT 主内核"策略再获一档（pad 路径已验证该布局收益真实：同 pool 下 NT 布局同 shape flag 低 25–43%，NT 大方形 8192³ 4.10ms≈268TF/s、4096×24576×8192 6.30ms、4096×8192×28672 sp 0.864 直接达标）——NN 现走 NN 布局需补一次 B 转置拷贝 ~0.5–1.5ms，净收 ~10–30%，预期该组 shape 仍不足 0.85，属最大单一杠杆但非达标解；② 向 Triton 后端寻求更宽 bf16 mmac 发射（指令宽度上限根治项，§3.1/§4 第 1 类）；③ TN 4095³ 残余转置拷贝开销融合（第 3 类唯一 shape）；④ 小奇数不 pad（§3.4 实验已定论）。
